# Chicago Traffic Camera Analysis

A Python and SQL application that analyzes Chicago traffic camera violation data and generates statistics and visualizations based on user-selected criteria.

## Overview

The Chicago Traffic Camera Analysis project was developed to explore and analyze traffic camera violation data from across the City of Chicago. By combining Python and SQL, the application allows users to query large datasets, compare violation trends, and generate meaningful insights through data analysis and visualization.

Users can investigate traffic camera activity at specific intersections, compare red-light and speed camera violations, and identify trends in violation data over time.

## Features

- Search camera data by intersection
- View violations per day
- Analyze violations by camera location
- Compare red-light camera violations to speed camera violations
- Generate visualizations based on user-selected criteria
- Query and process large datasets using SQL
- Produce statistical summaries from traffic violation records

## Technologies Used

- Python
- SQL
- SQLite

## Data

This project utilizes publicly available traffic camera violation data from the City of Chicago.

The database file is not included in this repository due to its size. To run the application, users must obtain the dataset separately and place the database file in the project directory.

## Example Questions Answered

The application can be used to answer questions such as:

- Which intersections generate the highest number of violations?
- How do red-light camera violations compare to speed camera violations?
- Which locations have the highest average violations per day?
- How have violations changed over time?
- What trends exist across different camera types and locations?
