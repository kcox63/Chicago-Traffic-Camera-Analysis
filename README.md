# Chicago-Traffic-Camera-Analysis
A Python and SQL application that analyzes Chicago traffic camera violation data and generates statistics and visualizations based on user-selected criteria.

Overview

This project was developed as part of coursework at the University of Illinois Chicago. The application allows users to explore and analyze traffic camera data from across the City of Chicago. Users can search for specific intersections, compare violation types, and generate visualizations to better understand traffic enforcement trends.

Features
Search camera data by intersection
View violations per day
Analyze violations by camera location
Compare red-light camera violations to speed camera violations
Generate visualizations based on user-selected criteria
Query and process large datasets using SQL

Data

This project uses traffic camera violation data from the City of Chicago.

The database file is not included in this repository due to its size. To run the project, users must download the dataset separately and place the database file in the project directory.

Example Analysis

The application can answer questions such as:

Which intersections generate the most violations?
How do red-light camera violations compare to speed camera violations?
What are the trends in violations over time?
Which locations have the highest average violations per day?
